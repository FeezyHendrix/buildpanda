## 4b. Activity/stage edge cases (from the plan's "Setup / programme" list)

42. **bug** · New site activity drawer · **Leaving "Location (optional)" blank makes creation fail.** Backend replies `400 must NOT have fewer than 1 characters` (`/location` minLength 1 — `dev.log` req-2oy) because the form sends `location: ""`. The drawer stays open with a tiny red "Request failed with status code 400" line at the bottom-right under the Panda AI bubble — nothing tells the PM that the *optional* field is the problem. Every activity I created had to have a Location. → Send `undefined`/omit when empty, or relax the schema; show the server message next to the field.
43. **bug** · New site activity drawer · When a server 4xx comes back the dialog only shows the raw axios text "Request failed with status code 400"; no field, no reason.
44. **bug (data + UX)** · Build stages → Delete a stage that has activities and a value · Confirm dialog says only "This removes the stage from the build plan. This action cannot be undone." — no mention that 2 activities and ₦38.25m of contract value hang off it. On Delete the request returns **HTTP 500** and the UI **silently closes the dialog, shows no error, and the stage stays** (screenshot `shots/05-delete-stage-confirm-no-warning.jpg`). Server log (`scratchpad/dev.log` req-2rf): `delete from "project_phases" ... null value in column "building_id" of relation "activities" violates not-null constraint` — the composite FK `(phase_id, building_id) ON DELETE SET NULL` (migration `20260602_site_activities_schema.ts` / building-scoped FK) tries to null `building_id`, which is NOT NULL. So **any stage with activities can never be deleted**, and the user is never told. Expected: either block with "Stage has 2 activities and a ₦38,250,000 value — reassign first" (409) or cascade/unlink cleanly; and surface the error.
45. **confusing** · Build stages → reorder · ▲/▼ works and persists (PATCH `/stages/reorder`). Moving "Demobilisation" above "Kerbs" was accepted with no comment even though its dates are later — stage order and stage dates are independent, and neither the stage table nor the Gantt flags the inversion. (Restored afterwards.)
46. **missing** · Build stages → Edit stage · Changing stage 1's end from 18 Sep to 30 Sep so it overlaps stages 2 and 3 saved silently — no overlap warning, no toast. Fine for a road (stages overlap by design) but a PM would expect at least an indicator. (Restored to 18 Sep.)
47. **cosmetic/bug** · Build stages · The **last row's kebab ("Actions") button sits under the floating Panda AI bubble** at 1680×856; a mouse click lands on the bubble. Also true for the last row on Site activity and Contracts & phases (the ⋮ of row 12 is hidden in `shots/05-…jpg`).
48. **bug** · Site activity → Delete · works (kebab → Delete → confirm) but there is no success toast; same for stage delete (which failed silently — see #44). The two "silent" outcomes look identical from the user's chair.
