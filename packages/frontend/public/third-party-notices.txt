   no LICENSE file. The Apache-2.0 text above applies; upstream source:
   https://github.com/dream-num/univer

2. rxjs@7.8.2 declares Apache-2.0 in its package.json but ships no LICENSE
   file in the npm artifact. Upstream license:
   https://github.com/ReactiveX/rxjs/blob/master/LICENSE.txt

3. franc-min@6.2.0 and ot-json1@1.0.2 ship no LICENSE file. Licenses are
   declared in their respective package.json files. Copyright notices are
   taken from the author field.

4. No @univerjs/* package ships a NOTICE file, so Apache-2.0 section 4(d)
   notice propagation does not apply.

5. @grpc/grpc-js, @grpc/proto-loader, and protobufjs are Univer transitives
   consumed only by @univerjs/rpc-node (a Node.js server-side package). They
   are not included in the browser bundle and are therefore not listed here.

6. This file covers new dependencies introduced by the Univer workbook feature.
   Pre-existing frontend dependencies (three.js, xeokit-sdk, etc.) are not
   audited here; that is a separate, repo-wide exercise.
